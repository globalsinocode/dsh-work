# 表格分组汇总

把员工上传的 Excel（xlsx）或 CSV 表格按某一列分组，对另一列求和，生成汇总表。

## 何时使用

员工要求“按区域/部门/产品汇总金额”“统计每个分组的合计”等，并附上了 xlsx 或 csv 文件。

## 怎么做

1. 看运行说明里有没有员工附件。**没有附件**（例如平台试运行）时，不要逐个目录查找文件，直接不带参数调用 `python_execute` 运行 `scripts/summarize.py`：脚本会用内置样例自检。然后告诉员工这是自检结果，请他上传要汇总的表格。
2. 有附件时，在运行说明中找到附件的**原始文件**路径（`input/original/` 下，只读），不要用解析文本 `input/*.txt` 代替。调用 `python_execute` 运行 `scripts/summarize.py`，参数依次为：
   - 原始文件的**绝对路径**（脚本的工作目录是 Skill 目录，相对路径会找错位置）；
   - 可选 `--group <列名>`，默认 `区域`；
   - 可选 `--value <列名>`，默认 `金额`；
   - `--name <运行说明中列出的原文件名，去掉扩展名>`：原始文件挂载后只保留 ASCII 字符，不传时输出文件名会变成下划线。
   例如 `args: ["/…/input/original/01-10____.xlsx", "--group", "区域", "--value", "金额", "--name", "10月区域销售"]`。
3. 脚本把 `<原文件名>-汇总.xlsx` 与 `<原文件名>-汇总.md` 写入输出目录，平台会登记为成果。按脚本的标准输出向员工说明分组数、总计与生成的文件。

## 出错时

- 脚本提示找不到列时，把它列出的表头告诉员工，请员工指定分组列和数值列后重跑。
- 输出写着“自检结果，不是业务结果”时，说明没有传入文件：不要把自检数字当作业务结论，也不要编造数据，请员工上传 xlsx 或 csv。
