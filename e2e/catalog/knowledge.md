# 知识库（WeKnora）

员工在工作台壳层内查阅 WeKnora 知识库。证据层级与写法见[验收目录索引](../TEST-CATALOG.md)。行为以 [26-10-29 知识库页面](../../docs/SDD/规格文档/26-10-29%20知识库页面.md) 为准。

### KB-E2E-01 工作模式进入知识库

**优先级：** P0  
**角色：** 员工（冒烟测试身份）  
**运行层级：** P0 冒烟服务、内存数据  
**前置数据：** 冒烟服务对知识库状态返回「尚未配置」，不连接 WeKnora  
**spec：** `e2e/personal-workbench.spec.ts`（实现阶段补断言；本条先定义旅程）

1. 打开 `/workbench`。主导航依次为「新对话、Skill 广场、AI 同事、项目空间、知识库、定时任务」。
2. 点「知识库」。地址为 `/knowledge`，侧栏仍在，页面说明知识库尚未配置，没有「连接知识库账号」。

**验收：** 入口在工作台内。冒烟不访问 WeKnora，也不把未配置显示成空知识库列表。

### KB-E2E-02 协作模式从头像菜单进入

**优先级：** P0  
**角色：** 员工（冒烟测试身份，已切换到协作模式）  
**运行层级：** P0 冒烟服务、内存数据  
**前置数据：** 与 KB-E2E-01 相同  
**spec：** `e2e/collab-mode.spec.ts`（实现阶段补断言）

1. 协作模式主导航仍是「对话、AI 同事、群组、定时任务」。
2. 打开头像菜单，点「知识库」。地址为 `/knowledge`，壳层仍是协作模式，页面说明尚未配置。
3. 切回工作模式后再打开 `/knowledge`：地址不变，壳层变为工作模式。

**验收：** 两种模式共用同一知识库地址。协作模式不把「知识库」放进那四个主导航入口。

### KB-E2E-03 已连接后的查阅与越权

**优先级：** P2  
**角色：** 两名已在 WeKnora 开通的员工  
**运行层级：** 真实 WeKnora 与真实 dsh-work 登录  
**前置数据：** 员工 A 至少有一个知识库；员工 B 无权访问该库  
**spec：** 发布前手工留证。P0 冒烟不能代替本条

1. 员工 A 打开「知识库」，不经过 WeKnora 登录页即可看到自己的库。
2. 进入该库，能看到文档；检索只出现该库的结果；预览或下载发生在工作台页面内。
3. 员工 B 打开 A 的库地址，看到无法打开，看不到 A 的文档正文。
4. 浏览器里这些请求的地址都属于工作台的 `/api/workbench/v1/integrations/weknora/`，响应中没有 WeKnora 访问令牌。

**验收：** 查阅身份是当前员工在 WeKnora 中的身份。未连接、未配置、空列表三种说明可以区分。
