# 员工端开发 PWA 安装

> 状态：待实现  
> 确认日期：2026-11-03  
> 结论口径：本地开发“弹”指 **Chrome 地址栏出现安装入口**，不做页面自动安装弹框。

## 范围

本期做：

- 员工端本地开发环境默认生成 PWA manifest 与开发版 Service Worker。
- 员工端开发环境注册 Service Worker 后，浏览器展示可安装入口。
- 修复生产构建遗漏 `push-sw.js` 导致员工端 PWA 无法安装的问题。
- 员工端自己的 `public` 文件与共享品牌静态资源在开发和构建时同时可用。

本期不做：

- 不新增应用内“安装工作台”按钮，也不自动弹出页面级安装确认框。
- 不改变 Web Push 订阅、通知内容或推送协议。
- 不改变生产 manifest 的名称、图标、`standalone`、`autoUpdate` 语义。
- 不让管理端默认启用开发 Service Worker，也不在管理端暴露 `push-sw.js`。
- 不把 `/api/*` 响应缓存为离线数据。

## 目标行为

| 场景 | 现在 | 改后 |
| --- | --- | --- |
| `pnpm dev:workbench` 后打开 `/workbench` | manifest 与开发 Service Worker 不生成，地址栏没有安装入口 | Service Worker 激活后，Chrome 地址栏出现安装入口 |
| 开发环境请求 `/push-sw.js` | 被 SPA 回退为 `index.html` | 返回原始 JavaScript，供开发 Service Worker `importScripts` 使用 |
| `pnpm build` 后的员工端 `dist` | 有 `sw.js`，但缺少 `push-sw.js`，生产安装失败 | `sw.js` 与 `push-sw.js` 同时存在 |
| 开发环境访问业务路由、`/api`、`/auth` | 正常 | 仍正常，不被导航回退错误拦截 |

## 边界

- `localhost` 可作为开发验证的安全上下文；正式安装仍以 HTTPS 部署为准。
- 开发 Service Worker 的导航回退仅允许 `/` 与 `/workbench/`，不允许 `/conversations/1`、`/api/*`、`/auth/*`。
- 员工端 `public` 文件与品牌资源同名时，员工端文件优先。
- 开发 Service Worker 只用于安装与壳层调试，不作为接口缓存策略。
- 浏览器是否立即展示安装入口仍受 Chrome 自身安装启发规则影响；本期只保证站点满足可安装条件，不做打扰式自动弹框。

## 涉及文件

| 路径 | 职责 |
| --- | --- |
| `apps/shared/vite-extra-public.ts` | 开发时服务员工端额外 public 文件，构建时复制到 `dist` |
| `apps/shared/vite-pwa-options.ts` | 增加员工端开发 PWA 配置开关与窄导航回退范围 |
| `apps/shared/register-app-pwa.ts` | 支持显式允许开发环境注册 Service Worker |
| `apps/workbench-web/vite.config.ts` | 接入额外 public 目录与开发 PWA 开关 |
| `apps/workbench-web/src/main.ts` | 员工端开发环境显式注册 PWA |
| `apps/workbench-web/src/__test__/*.test.ts` | 覆盖路径安全、MIME、开发开关与资源复制 |
| `.gitignore` | 忽略 `apps/*/dev-dist/` |

## 验收

- 员工端现有开发命令启动后，`/manifest.webmanifest` 返回 JSON，`/dev-sw.js?dev-sw` 与 `/push-sw.js` 返回 JavaScript。
- 开发 Service Worker 激活后刷新 `/workbench`，Chrome 地址栏出现安装入口或浏览器菜单出现“安装 dsh-work 员工 AI 工作台”。
- 生产构建后 `dist` 同时包含 `manifest.webmanifest`、`sw.js`、`push-sw.js`、`pwa-192.png`、`pwa-512.png`。
- 员工端相关 Vitest、lint、typecheck 与生产 build 通过。
- 开发环境访问 `/api/health` 仍走开发代理，不被 Service Worker 返回 `index.html`。
