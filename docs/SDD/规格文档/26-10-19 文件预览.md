# 26-10-19 文件预览

**状态：** 已与需求方逐项确认，待实现。本文只定义成果文件的直接预览，不授权另建下载通道或第二套 Agent 执行链路。
**确认日期：** 2026-10-19

## 1. 要达成的效果

员工在看见一份**成果**时，点击文件名或卡片主体就打开预览对话框，能直接看内容。下载改为旁边的独立操作，不再占用主点击。

预览的是该条目上展示的那个版本。能通过现有成果下载接口取回该版本的人，就能预览；个人空间与已归档空间与下载同一读取口径。不新增公开链接，不新增权限字段。

## 2. 现在的行为

| 位置 | 现在 |
| --- | --- |
| 我的成果、工作空间「成果」页的 `ArtifactCard` | 仅 HTML 有「预览」按钮，打开沙箱对话框（渲染预览 / 源代码 / 下载）。其余类型只有「下载」。 |
| 对话消息中的成果条 | 整条点击即下载。符合条件时另有「继续修改」。 |
| 本轮执行详情抽屉中的成果列表 | 整行点击即下载。 |
| 预览对话框 `ArtifactPreviewDialog` | 只按 HTML 处理：鉴权下载后注入预览 CSP，放入 `sandbox="allow-scripts"` 且不带 `allow-same-origin` 的 iframe。 |

成果类型现为 `xlsx`、`docx`、`pdf`、`markdown`、`csv`、`text`、`html`。成果体积已由服务端限制为 1 B～10 MB。预览不再另设体积门槛。

## 3. 类型与对话框内容

同一个对话框按成果 `type` 切换主体。标题始终包含「成果预览」和文件名，并标出版本号。头部保留「下载」和关闭。

| 类型 | 打开后看到 |
| --- | --- |
| HTML | 维持现有沙箱：默认「渲染预览」，可切「源代码」。CSP、opaque origin、竞态作废保持不变。 |
| Markdown | 渲染标题、列表、表格、代码块、链接和图片替代文字。区域内滚动看全文。 |
| CSV | 表格展示全部列、最多前 500 行数据。超出时在表格上方写明「仅显示前 500 行，完整内容请下载」。 |
| 纯文本 | 等宽字体展示全文，区域内滚动。 |
| PDF | 对话框内用浏览器原生查看整份文件，不截断。 |
| Excel、Word | 说明「暂不支持在线预览」，并提供下载。不解析、不转换文件内容。 |

Markdown 原文中的 HTML 标签按普通文字显示，不插入页面、不执行脚本。链接拒绝 `javascript:`。HTML 成果继续只走沙箱，不与 Markdown 渲染混用。

加载、失败与切换：

- 内容未返回时，对话框内显示骨架屏。
- 加载失败时说明失败原因的用户可见文案为「成果内容加载失败」，并提供「重试」和「下载」。
- 打开、关闭或换一份成果时，先作废在途请求并清空上一份内容，避免 A 的内容出现在 B 的标题下。
- 空文件仍显示对应的空预览，不当成加载失败。

PDF 与文本类内容都经现有 `downloadArtifact(id, version)` 取回 blob 后再展示。不把下载 URL 直接交给浏览器地址栏，以免触发附件下载或绕过鉴权头。PDF 使用的临时对象 URL 在关闭、切换成果和组件卸载时释放。

## 4. 各入口的点击

| 入口 | 主点击 | 其他操作 |
| --- | --- | --- |
| 对话消息中的成果条 | 文件名区域打开预览 | 旁边独立「下载」。本轮、且该成果可引用并带有 `fileId` 时，「继续修改」保持现有条件与文案。 |
| 本轮执行详情中的成果 | 名称打开预览 | 旁边独立「下载」。 |
| 我的成果、工作空间「成果」卡片 | 名称或卡片主体打开预览 | 操作区只留「下载」。去掉仅 HTML 才出现的「预览」按钮。Excel、Word 点开后仍进同一对话框。 |

预览版本等于卡片或条目上的 `version`。

## 6. 改动范围

只改员工端展示与现有下载读取，不改 DSH、不改成果登记。

| 位置 | 改动 |
| --- | --- |
| `packages/ui-core/src/components/ArtifactCard.vue` | 名称或卡片主体触发 `preview`（全部类型）。操作区只保留下载。删除 `type === 'html'` 才渲染的「预览」按钮。 |
| `apps/workbench-web/src/components/ArtifactPreviewDialog.vue` | 按类型渲染 HTML 沙箱、Markdown、CSV、纯文本、PDF，以及 Excel/Word 的不支持说明。沿用现有打开、下载、关闭、请求世代号和失败重试。 |
| `apps/workbench-web/src/views/ConversationView.vue` | 消息成果条与执行详情列表：主点击改为打开同一预览对话框；下载拆成独立按钮。挂上 `ArtifactPreviewDialog`。 |
| `apps/workbench-web/src/views/ArtifactsView.vue`、`WorkspaceDetailView.vue` | 已有预览对话框接线可保留；卡片改为点主体即预览后，两处仍把 `preview` 事件交给现有对话框。 |
| 对应单测 | 卡片主点击、分类型对话框、对话与抽屉不再一点击就下载、CSV 500 行截断、Markdown 不执行 HTML、切换成果不串内容。 |

不修改「我的文件」、工作空间文件行和版本历史对话框。

## 7. 验收

1. 在对话、执行详情、我的成果、工作空间成果页，点击成果名称都打开预览，且不会同时开始下载。
2. 上述位置的「下载」仍下载条目上的那个版本。
3. 对话里符合原条件的成果仍可「继续修改」；已引用后的禁用与文案不变。
4. HTML 仍可在渲染预览与源代码之间切换，脚本不能访问工作台页面、Cookie 或存储。
5. Markdown、CSV、纯文本、PDF 能在对话框内看到第 3 节描述的内容；CSV 超过 500 行时有截断说明。
6. Excel、Word 打开后看到暂不支持在线预览，并能从对话框下载。
7. 加载失败可重试；快速切换两份成果时，后打开的标题下不会留下前一份内容。
8. 无下载权限时预览失败，表现与下载被拒绝一致，不出现未鉴权的文件地址。
9. 我的文件、空间文件页、版本历史的点击行为与本期改动前一致。
