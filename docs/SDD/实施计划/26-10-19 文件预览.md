# 成果文件直接预览 实现计划

> **面向实现者：** 按任务顺序做。每步先写测试并看到失败，再写最少实现。步骤使用 `- [ ]` 跟踪。提交只在用户明确要求时执行；未要求时停在工作区改动。
>
> **规格：** [26-10-19 文件预览](../规格文档/26-10-19 文件预览.md)

**目标：** 员工点击成果名称或卡片主体即打开预览；下载改为独立按钮。HTML 沿用沙箱，Markdown / CSV / 纯文本 / PDF 在同一对话框内查看，Excel 与 Word 只说明暂不支持在线预览。

**架构：** 不新增接口、权限或转换服务。预览仍调用 `workbenchApi.downloadArtifact(id, version)` 取回 blob。纯函数负责 Markdown 安全渲染和 CSV 截断；`ArtifactPreviewDialog` 按 `artifact.type` 切换主体；`ArtifactCard` 与对话页只改点击目标。Excel / Word 打开对话框时不请求文件字节。

**技术栈：** Vue 3 `<script setup lang="ts">`、Element Plus、Vitest + `@vue/test-utils`、现有 Playwright P0 冒烟。不新增 npm 依赖。

**不改：** 服务端、DSH、成果登记、「我的文件」、工作空间「文件」页、版本历史对话框。

- [ ] **步骤 3：实现纯函数**

`artifact-preview.ts` 至少包含：

```ts
export const CSV_PREVIEW_MAX_ROWS = 500

export interface CsvPreview {
  headers: string[]
  rows: string[][]
  truncated: boolean
}

function escapeHtml(value: string) {
  return value
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;')
}

function safeHref(url: string) {
  const trimmed = url.trim()
  if (/^https?:\/\//i.test(trimmed) || /^mailto:/i.test(trimmed)) return trimmed
  return null
}
```

`renderMarkdownPreview` 先整体按行处理，不要把原文交给 `v-html` 之外的 HTML 解析器再拼回去。规则：

- 围栏代码块（` ``` `）内部全部 `escapeHtml`，包在 `<pre><code>` 中。块内不解析 Markdown。
- `#` 至 `######` 标题变成对应 `h1`–`h6`，标题文字 `escapeHtml`。
- 以 `|` 开头的连续行，第二行是 `| --- |` 这种分隔时，渲染 `<table>`。单元格文字 `escapeHtml`。
- `- ` 或 `* ` 连续行渲染 `<ul><li>`；`1. ` 这种渲染 `<ol><li>`。
- `![alt](url)` 只输出 `escapeHtml(alt)`，不输出 `<img>`，不保留 url。
- `[text](url)`：`safeHref(url)` 有值时输出 `<a href="..." rel="noopener noreferrer">`；否则只输出转义后的文字，整段不得留下 `javascript:`。
- 其余非空行作为段落。行内若出现未包在上述语法里的 `<`，必须已被 `escapeHtml` 转成 `&lt;`。
- 空字符串返回空字符串。

`parseCsvPreview`：

- 空字符串返回 `{ headers: [], rows: [], truncated: false }`。
- 按 RFC 4180 读取记录：逗号分隔，双引号包裹字段，字段内 `""` 表示一个引号，引号字段可含逗号和换行。
- 第一条记录是 `headers`。其后是数据行。
- 数据行超过 `CSV_PREVIEW_MAX_ROWS` 时只保留前 500 行，`truncated` 为 `true`。恰好 500 行时 `truncated` 为 `false`。
- 不补列、不丢列。

- [ ] **步骤 3：扩展对话框**

在 `ArtifactPreviewDialog.vue` 中：

- `type === 'xlsx' || type === 'docx'` 时不要调用 `downloadArtifact`。清空内容、`error = false`、`loading = false`。
- `pdf`、`markdown`、`csv`、`text`、`html` 仍走现有 `loadContent` 的世代号。晚到响应的丢弃逻辑不变。
- `pdf` 把 blob 交给 `URL.createObjectURL`。切换成果、关闭、卸载时对上一个地址调用 `URL.revokeObjectURL`。iframe 使用 `data-testid="artifact-preview-pdf"`、`referrerpolicy="no-referrer"`、`:title="成果预览：文件名"`。不要加 `sandbox`：浏览器内置 PDF 查看器在沙箱 iframe 中经常无法显示。地址必须是对象 URL，不能把 `artifactDownloadUrl` 写进 `src`。
- `markdown` 用 `v-html="renderMarkdownPreview(text)"`，容器 `data-testid="artifact-preview-markdown"`。禁止把下载到的原始字符串直接 `v-html`。
- `csv` 用 `parseCsvPreview`。`truncated` 时显示文案「仅显示前 500 行，完整内容请下载」，`data-testid="artifact-preview-csv-notice"`。表格 `data-testid="artifact-preview-csv"`，表头全部列出。
- `text` 用 `<pre data-testid="artifact-preview-text">`。
- 空 blob 文本：不进入错误态。文本是空的 `<pre>`，Markdown 是空容器，CSV 是空表格。
- 「渲染预览 / 源代码」单选只在 `type === 'html'` 时渲染。HTML 的 CSP、`sandbox="allow-scripts"`、源代码视图保持现有函数 `withPreviewCsp`。
- HTML 提示句保持「内容在隔离沙箱中渲染……」。其他类型不要写沙箱提示，只保留版本，例如 `V2`。
- Office 主体：`<p data-testid="artifact-preview-unsupported">暂不支持在线预览</p>`。头部下载按钮继续调用现有 `download()`。
- 失败态文案保持「成果内容加载失败」，保留重试与头部下载。
