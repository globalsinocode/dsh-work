## 后端（本仓库 server，已完成）

- 迁移 `0109_web_push.sql`：`push_subscriptions`、`notification_preferences`
- `WebPushService` / `WebPushDispatchService`：协作未读、Run 终态推送

- 集成测试：`server/src/http/web-push-api.integration.test.ts`

## 前端 PC（`apps/workbench-web`，移动由 `dsh-work-mobile` 维护）

1. Workbox `importScripts` → `public/push-sw.js`（标签页在后台或未聚焦时走浏览器系统通知）
2. `useSystemNotifications`：顶部条 + 未读轮询 + Run 终态；**PC 不在登录时自动弹权限**，在用户中心打开「系统通知」时订阅
3. `system-notification-banner`（宽屏居中条）、`notification-settings` 在 **用户中心** 对 PC 始终展示
4. 退出登录注销本机 Push 订阅
5. 发起人「允许本次 / 拒绝」、`/chat/:sessionId` 路由（与移动共用后端契约）
