**Goal:** 在目标机 `dev@074e009` 的后继上关闭工具治理冲突、岗位权限能力摘要、PF-MCP-01 与剩余 P1 浏览器红项，使 release 2026.10.26-01 的四层门禁重新全绿。

**Architecture:** 目标机返回的缺陷清单是事实权威；旧工作副本不得重造目标机已完成提交。先通过 Git 基线门禁，再确认唯一工具治理模型；能力摘要必须读取该权威模型，MCP 管理面和执行面必须共享同一生效快照。每个修复先建立失败证据，再做最小实现并运行窄测试，最后才运行全量门禁。

**Tech Stack:** Node.js 22.19+/24、TypeScript、PostgreSQL、Vue 3、Element Plus、Vitest、Node test runner、Playwright、DSH Runtime Adapter。
