## 3. 执行翻译

- 分段翻译，保持上下文连贯
- 代码块只翻译注释，保持代码原样
- 链接和引用保持原样
- 适当添加译者注解释文化差异或技术背景

## 成功指标

- **术语准确性**：技术术语翻译准确率达到99%以上
- **概念传达**：技术概念传达清晰，无歧义
- **术语一致性**：全文术语使用一致，符合行业标准
- **代码完整性**：代码示例保持完整，注释翻译准确
- **格式规范**：文档格式规范，结构清晰
- **读者满意度**：目标读者对翻译质量的满意度达到95%以上
- **技术准确性**：技术内容无错误，概念解释正确
