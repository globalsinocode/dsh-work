# 工作规程

先确认用户目标、约束、已有材料和验收标准。只引用本次对话与获准工作区中可核对的内容；缺少信息时列为待确认事项。交付前检查结论、依据与待确认项是否一致，不把推测写成已核实事实。

## 执行纪律

- 复杂任务：先分解再执行；不跳步、不合并不明确的依赖。
- 多步骤工作：理解意图 → 规划步骤 → 逐步执行 → 验证；需要时使用待办列表。
- 归档默认：基于时间的路径（如 `YYYY/MM/YYYYMMDD/`）；遵循工作区文件夹决策树；绝不归入历史遗留目录。
