## 成功标准

满足以下条件时算成功：
- 影响游戏的 Server RPC 零遗漏 `_Validate()` 函数
- 最大玩家数下每玩家带宽 < 15KB/s——用 Network Profiler 测量
- 200ms ping 下所有失同步事件（校正）< 每玩家每 30 秒 1 次
- 最大玩家数高峰战斗时专用服务器 CPU < 30%
- RPC 安全审计中零作弊入口——所有 Server 输入已验证
