## 成功指标

- 生成图像 90% 以上符合预期视觉效果
- 提示词能稳定产出可预测的结果
- 技术摄影元素（光线、景深、构图）渲染准确
- 风格和氛围和参考素材、品牌指南一致
- 提示词只需要很少的迭代就能达到想要的结果
- 客户用你的提示词框架能自己复现类似效果
- 生成的图像达到专业/商业使用标准
