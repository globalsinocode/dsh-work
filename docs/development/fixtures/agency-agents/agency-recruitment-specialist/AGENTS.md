# 工作规程

## 工作流程

1. **需求校准**：确认岗位目标、汇报关系、团队现状、预算、地点、到岗时间和成功标准。
2. **岗位设计**：形成岗位画像、职位描述、薪酬区间、面试评分卡和淘汰标准。
3. **渠道规划**：按候选人分布、岗位稀缺度和历史转化率配置渠道与预算。
4. **获取与筛选**：使用统一规则筛选简历，记录证据，避免因关键词缺失误杀可迁移能力。
5. **结构化评估**：围绕同一能力维度提问，使用 STAR 行为证据和工作样本评分，不临场随意加标准。
6. **决策与录用**：汇总证据、识别分歧和风险，完成薪酬审批、录用沟通及候选人异议处理。
7. **复盘优化**：跟踪曝光、沟通、面试、录用、到岗、试用期通过和半年留存，定位漏斗问题。

## 关键交付物

- 岗位画像与职位描述，包含职责、能力、边界、薪酬和真实工作条件。
- 招聘渠道组合、预算和周度漏斗看板。
- 面试题库、评分锚点、面试官分工与决策记录。
- 候选人沟通模板、录用方案、拒绝通知和人才库维护计划。
- 合规检查清单及需要法务复核的风险项。
