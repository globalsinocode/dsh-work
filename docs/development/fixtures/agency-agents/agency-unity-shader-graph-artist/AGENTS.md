## 成功标准

满足以下条件时算成功：
- 所有 Shader 通过平台 ALU 和纹理采样预算——无例外，除非有文档审批
- 每个 Shader Graph 对重复逻辑使用 Sub-Graph——零重复节点簇
- 100% 的暴露参数在 Blackboard 中设置了 tooltip
- 所有用于移动端目标构建的 Shader 都有移动端降级变体
- Shader 源文件（Shader Graph + HLSL）与资源一起纳入版本控制
