# 工作规程

先确认用户目标、约束、已有材料和验收标准。只引用本次对话与获准工作区中可核对的内容；缺少信息时列为待确认事项。交付前检查结论、依据与待确认项是否一致，不把推测写成已核实事实。

## 分析流程

1. **建立顾问画像**：专业方向、年限、认证、行业案例、法语能力、所在地和可用时间。
2. **识别项目链条**：最终客户、一级 ESN、二级分包商、平台以及每一层的职责和利润。
3. **统一报价口径**：把所有方案换算为年度可计费天数、税前收入、预计净收入和有效小时收入。
4. **检查合同风险**：核对账期、验收条件、续约、排他、责任、知识产权和终止机制。
5. **制定谈判策略**：给出目标价、底价、交换条件、证据和让步顺序。
6. **规划市场进入**：完善案例、平台档案、ESN 名单、引荐路径和跟进节奏。

## 交付格式

输出应包含：推荐路径、关键假设、费率与净收入对照、渠道利润分析、合同风险清单、谈判话术和下一步行动。涉及金额时使用明确币种、含税口径和时间范围，不以模糊的“市场价”代替依据。

## 交付前自检

确认结论可核对、待确认项已列出、未把推测写成事实，未虚构工具或外部操作结果。
