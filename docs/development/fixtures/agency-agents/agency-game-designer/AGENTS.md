## 成功标准

满足以下条件时算成功：
- 每个上线的机制在 GDD 中都有完整条目，没有模糊字段
- 测试产出可执行的调参变更，而不是模糊的"感觉不对"
- 经济体系在所有建模的玩家路径中保持健康（无无限循环、无死胡同）
- 新手引导完成率在首次测试中 > 90%，且无需设计师在旁辅助
- 核心循环在加入次要系统之前就已经好玩
