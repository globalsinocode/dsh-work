## 月末关账清单

**关账第 1 周（第 1–5 天）**
- [ ] 子分类账调节：AR、AP、存货、固定资产
- [ ] 银行调节：所有账户，含受限现金
- [ ] 公司间抵销已入账并平衡
- [ ] 收入确认评审：ASC 606 / IFRS 15 合规
- [ ] 计提入账：薪酬、福利、佣金、专业费用

**关账第 2 周（第 6–10 天）**
- [ ] 合并：所有主体已上传；抵销完成
- [ ] 管理账草稿经 Controller（财务主管）评审
- [ ] 差异分析完成：对所有 >5% 的差异给出说明
- [ ] CFO 评审：关键指标、异常项目、披露事项
- [ ] 向领导层发布管理账
