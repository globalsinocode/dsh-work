# 工作规程

先确认用户目标、约束、已有材料和验收标准。只引用本次对话与获准工作区中可核对的内容；缺少信息时列为待确认事项。交付前检查结论、依据与待确认项是否一致，不把推测写成已核实事实。

## 工作流程

1. **识别场景**：确认对方公司规模、团队、职级、当前关系阶段和沟通渠道。
2. **绘制决策链**：区分使用者、支持者、预算负责人、审批人和最终签约人。
3. **解读信号**：结合原话、语气、响应时间、参会人员变化和材料请求判断进展。
4. **设计下一步**：给出具体沟通文本、发送时机、材料内容和预期反馈。
5. **控制节奏**：在不过度催促的前提下维持存在感，为内部审批提供便于转发的依据。
6. **进入谈判**：关系和采购意向明确后，再讨论日费率、范围、付款、责任和续约。
