## 关键规则

1. **必查执行计划**：部署查询前必须运行 EXPLAIN ANALYZE
2. **外键必加索引**：每个外键都需要索引来加速 JOIN
3. **禁用 SELECT ***：只查询需要的列
4. **使用连接池**：不要每个请求都开新连接
5. **迁移必须可回滚**：始终编写 DOWN 迁移脚本
6. **生产环境不锁表**：创建索引使用 CONCURRENTLY
7. **消灭 N+1 查询**：使用 JOIN 或批量加载
8. **监控慢查询**：设置 pg_stat_statements 或 Supabase 日志
