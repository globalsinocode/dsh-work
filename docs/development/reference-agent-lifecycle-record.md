# 通用文本整理助手生命周期记录

**用途：** 验证通用 Agent 生命周期模板和严格 Agent 包契约的场景无关参考，不作为生产发布申请。  
**参考包：** [`fixtures/reference-text-agent`](fixtures/reference-text-agent)。  
**当前证据层级：** 静态包解析与契约测试；未创建发布候选、Binding、Run/Attempt 或 P2 记录。

## 1. 工作定义

| 字段 | 记录 |
| --- | --- |
| Agent 标识与名称 | `reference-text-agent`；通用文本整理助手 |
| 负责人 | 文档示例，无生产业务负责人；代码所有者负责契约维护 |
| 业务目标 | 将用户直接提供的文本整理为简洁的摘要、要点和待确认信息 |
| 范围外事项 | 不访问外部系统，不读取未提供的数据，不执行写操作，不替用户作业务决定，不声称任务已在外部完成 |
| 用户与入口 | 参考包解析和发布流程测试；没有生产入口 |
| 输入 | 用户直接提供的文本；缺少原文或目标时要求补充 |
| 输出与完成判据 | 文本输出；忠实反映输入，区分事实与待确认事项，不添加输入中没有的结论 |
| 权威业务事实 | 只有本次输入；不存在外部权威业务系统 |
| 能力依赖 | 无 Skill、Tool 或额外模型能力要求 |
| 上下文 | 最近对话历史；不得将历史内容当作当前输入未提供的业务事实 |
| 执行限制 | 120 秒、最多 1 次工具调用配额、32 KiB 输出；参考定义本身不声明工具 |
| 环境与绑定 | 无外部能力，因此无 Tool Binding；若改为生产发布仍须由平台环境和身份策略准入 |
| 评测 | 包内 `AgentEvaluationSuite v1` 五类案例 |
| 发布与验收 | 当前只验证严格包格式和评测加载；不宣称已发布或完成 P2 |

## 2. 能力分解

| 工作 | 执行者 | 输入与输出 | 权限边界 |
| --- | --- | --- | --- |
| 理解整理目标 | 单次 DSH Agent Loop 中的模型 | 用户文本 → 整理计划 | 只使用已提供内容 |
| 生成摘要和要点 | 模型 | 原文 → 文本结果 | 不调用工具，不补造来源 |
| 识别缺失信息 | 模型 | 不完整请求 → 澄清问题 | 不猜测缺失事实 |
| 完成判定 | 人工 rubric；生产场景可另加确定性规则 | 输出 → 通过/不通过 | 模型自述不构成通过证据 |

## 3. 扩展决策

| 扩展 | 选择 | 理由与替代方案 |
| --- | --- | --- |
| MCP | 不启用 | 没有外部 MCP Server 或远端能力需求 |
| 持久化等待 | 不启用 | 单次文本整理无需等待人工回调或未来事件；信息不足时结束本次执行并要求补充 |
| 受控记忆 | 不启用 | 不需要跨 Session 偏好或经验；输入与最近上下文足够 |
| Agent 委派 | 不启用 | 没有独立子任务或另一个发布 Agent |
| 无 Session 入口 | 不启用 | 参考流程使用现有会话和发布试运行路径 |
| 结构化交互 | 不启用 | 文本输入输出足以验证当前目标 |

## 4. AgentSpec、评测和证据

参考包明确声明文本输入输出、recent 上下文、运行限制、空模型能力要求和评测路径。`checksums.json` 覆盖包内全部文件（自身除外）。包解析测试直接从仓库目录构建 ZIP 并调用生产 `parseAgentPackage`，用于发现参考文档与 Schema、默认值或评测契约的漂移。

五类案例分别验证：忠实整理、缺少原文、越权读取、提示注入和外部能力不可用。机器断言只证明 Run/Attempt、执行终态和非空输出；是否忠实、是否泄露或是否虚构外部动作由 rubric 判断。

## 5. 后续阶段边界

该参考记录没有具体生产负责人、目标身份、发布环境和业务验收人，因此止于生命周期第 6 阶段。若要将其作为真实 Agent 发布，必须创建候选，在目标环境完成能力准入、DSH 试运行、审核、发布和 P2 归档；不得复用本记录的静态解析结果宣称这些阶段已经完成。
