## 2026-10-27 修复 Windows 下 Skill 落盘误判 Unsafe resource path

- **原因**：`dsh-acp-runtime-adapter` 用 `` `${root}/` `` 判断子路径，在 Windows 上 `resolve` 结果为反斜杠，合法 Skill 文件被误判为越界，Run 以 `RUNTIME_DISPATCH_FAILED` 失败。
- **做了什么**：Skill/挂载/检查点路径校验改为复用 `isStrictResolvedPathInside`（`host-path` 跨平台语义）。
- **涉及文件**：`server/src/modules/runtime/dsh-acp-runtime-adapter.ts`、`server/src/modules/runtime/contained-resolved-path.ts`。

## 2026-10-27 修复带 clientIntentId 新建对话首跑因 draft Session 被拒

- **原因**：前端 `createTask` 创建会话时带 `clientIntentId`，服务端落库为 `draft`；紧接着 `startRun` 在 `createRun` 里只接受 `status = active`，触发「Session 不存在或不可访问」。

- **涉及文件**：`server/src/modules/run/postgres-run-repository.ts`、`server/src/modules/workbench/application/postgres-conversation-repository.ts`、`server/src/infrastructure/postgres/m3-orchestration.integration.test.ts`。
