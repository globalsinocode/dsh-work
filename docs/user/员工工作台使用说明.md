# dsh-work 员工工作台使用手册

本手册面向企业员工，介绍员工工作台的主要功能和常用操作。内容已按当前仓库中的界面、接口和测试用例核对。实际可见的 Skill、AI 同事、团队空间和企业数据，由管理员已发布的内容、你的账号权限及所在环境共同决定。

## 1. dsh-work 是什么

dsh-work 是企业统一的 AI 工作台。你可以用自然语言提出需求，让 AI 同事在**你的企业身份和授权范围**内查询知识、引用业务数据或分析办公文件。任务产生的回答可在对话中继续追问；已登记的表格、报告等**成果文件**可下载，支持的类型还可在线预览或引用到后续对话。

工作台负责对话、文件、团队空间和自动任务；具体的 AI 能力与业务工具由企业统一配置和发布。对话页底部会提示：**AI 生成内容可能存在误差，重要业务结论请结合来源与企业制度确认。**

## 2. 能力范围（你能做什么）

在权限允许的前提下，员工工作台当前支持：

| 能力 | 说明 |
| --- | --- |
| 统一对话 | 从「新对话」、Skill 广场或 AI 同事入口发起任务，多轮续写同一话题 |
| 上下文引用 | 上传本地文件，或从「我的文件」、团队共享文件中选择可引用文件；按需在问题中插入「企业数据」标记 |
| 成果交付 | 对话结束后查看、预览、下载成果；可将成果「继续修改」带入下一轮 |
| 个人与团队内容 | 个人对话和文件默认仅本人可访问；团队空间用于共享对话、文件和成果 |
| 目录与发现 | 浏览已发布的 Skill 与 AI 同事，查看说明与示例提问 |
| 自动任务 | 按固定提示词定时或手动触发 AI 同事；查看执行记录与关联会话 |
| 文件集中管理 | 「我的文件」汇总个人材料、会话附件与生成成果 |
| 历史追溯 | 「历史对话」按标题搜索，区分个人与团队会话并继续 |

**边界说明（使用口径）：**

- 任务按**当前登录身份**和**当前工作空间**的权限执行；输入框旁会标明「按企业身份与资源权限执行」或「按企业身份和工作空间权限执行」。
- 你能看到的 Skill、AI 同事、团队空间与文件列表，均以企业已发布配置和你的成员身份为准。
- 团队空间**归档**后，仍可查看与下载历史内容，但不能再发起新对话、上传或续写（负责人可恢复空间）。

## 3. 登录与进入工作台

1. 使用企业提供的登录方式进入员工工作台。页面可能提供账号密码登录、AI Hub 企业登录，或同时提供两者，以所在环境的配置为准。
2. 登录成功后默认进入 **新对话**（`/workbench`）。
3. 若需修改本地账号密码，可在 **用户中心** 进入「修改密码」。

具备管理权限的账号，可在左下角用户菜单中选择 **打开管理后台**（管理功能不在本文展开）。

## 4. 工作台布局

### 4.1 左侧主导航（五个入口）

| 入口 | 用途 |
| --- | --- |
| **新对话** | 发起默认归入个人空间的任务 |
| **Skill 广场** | 浏览企业已发布的 Skill，查看说明后一键使用 |
| **AI 同事** | 浏览已发布的 AI 同事（Agent），查看开场提示与示例问题 |
| **团队空间** | 进入已加入的团队空间，进行协作、共享文件与成果管理 |
| **自动任务** | 管理你创建的定时/手动任务，查看执行记录 |

顶部 **发起新对话** 按钮与「新对话」入口作用相同，会打开空白对话页。

### 4.2 最近对话

侧栏列出近期会话。点击标题进入对话；在「更多」菜单中可：

- **复制对话链接**
- **导出对话记录**（文本文件）
- **移除对话**（进行中的任务需先停止；归档空间内的对话不可移除）

### 4.3 其他常用页面

以下功能保留完整能力，通常通过链接、文件来源或书签进入：

- **历史对话**（`/history`）：按标题搜索，筛选「全部 / 我的对话 / 团队对话」
- **我的文件**（`/files`）：按来源筛选个人材料、会话附件、生成成果

### 4.4 用户中心

左下角头像菜单 → **个人资料与设置**，可查看姓名、员工编号、部门、角色与**数据范围**，以及内容保留与账号停用相关说明。

## 5. 发起对话

### 5.1 从哪里开始

- **新对话页**：直接输入任务。
- **Skill 广场**：在卡片或详情中点击「使用 Skill」或「去对话」。
- **AI 同事**：在卡片中点击「去对话」，或在详情中点击「开始对话」。
- **团队空间 → 对话**：在指定团队空间中发起讨论或 AI 任务，对话归属该空间。
- **我的文件 / 团队空间的共享文件**：对页面标记为可引用的文件，点击「引用到新对话」或「引用到对话」。

### 5.2 输入框能做什么

在对话输入框中：

1. **输入任务**：说清目标、已知条件和希望的输出格式。
2. **选择 AI 同事**：个人对话可从「AI 同事」页面选择后发起；团队空间中，输入 `@` 并从候选列表选择空间内的 AI 同事成员。
3. **添加本地文件**：点击输入框左下角「+」→「上传本地文件」。支持 `.pdf`、`.docx`、`.xlsx`、`.xls`、`.csv`、`.txt`、`.md`；每次对话最多添加 5 个文件，单个文件不超过 20 MB。
4. **引用已有文件**：
   - 在个人对话中选择「+」→「我的文件」，进入文件页后对可引用文件点击「引用到新对话」。
   - 在团队空间中打开「共享文件」，对可引用文件点击「引用到对话」。
5. **引用企业数据**：选择「+」→「引用企业数据」，在问题中插入 `@企业数据` 标记。该标记不会扩大权限；是否能读取相关数据，仍取决于当前 AI 同事的工具和你的数据权限。
6. **确认内容归属**：从「新对话」发起的对话默认归入个人空间；需要在团队内共享时，请先进入「团队空间」，再从该空间的「对话」页签发起。团队对话的归属空间不可在输入框中切换。
7. **发送或停止**：点击发送按钮提交。本轮执行中，同一按钮会变为「停止本轮执行」；停止后，已有对话和执行记录仍会保留。

带 **Skill** 的对话会在界面标明所用 Skill 名称与版本。

### 5.3 团队空间中的两种消息

在**团队空间**的对话中：

- **不 @ 任何人**：发送的是**全员可见的讨论消息**，用于同步信息，**不会**自动触发 AI 执行。
- **@ 某个 AI 同事成员**：发起一次 **执行（Run）**，由该同事在授权范围内处理任务。

若消息带有**附件**或**引用成果**，需要 **@ Agent** 才能发起执行；纯讨论消息不支持带附件。

## 6. 查看对话结果与执行过程

### 6.1 对话主界面

- 查看你与 AI 同事的消息记录；团队会话会显示发送人与「由谁发起」的执行信息。
- 进行中会显示当前步骤，可打开 **查看执行过程** 了解工具调用与阶段说明。
- 若企业配置了受控工具且本轮需要确认，页面会提示 **等待工具权限确认**，按指引完成后再继续。

### 6.2 对话详情侧栏（或抽屉）

在支持详情的视图中可查看：

- **当前执行**：会话 ID、运行 ID、Agent 版本、团队归属等
- **结果核验**：摘要、待确认项、回执信息、成果登记情况、工具调用统计等
- **本轮执行步骤**：逐步执行记录
- **数据来源**：本轮引用的知识、Skill、文件等来源说明
- **成果文件**：本轮生成的文件列表，支持下载

### 6.3 失败、停止与重试

- 执行失败时会展示原因与建议的下一步操作。
- 停止后记录保留，可在允许的情况下 **重新执行** 或继续用文字补充说明。
- 归档空间内的对话为只读：可查看与下载，不能续写或重试。

### 6.4 成果：下载与继续修改

- 在消息或成果列表中 **下载** 文件。
- 对支持续写的成果点击 **继续修改**：系统会把该成果作为只读输入带入你的下一条消息；若 AI 再次输出同名文件，会登记为**新版本**，旧版本仍可下载。

## 7. 成果预览

在 **团队空间 → 成果** 或对话中的成果入口，可打开 **成果预览**（与下载权限一致）。按文件类型：

| 类型 | 预览方式 |
| --- | --- |
| HTML | 默认渲染预览，可切换查看源代码 |
| Markdown | 页面内渲染标题、列表、表格、代码块等 |
| CSV | 表格展示，最多前 500 行（超出时提示下载完整文件） |
| 纯文本 | 等宽字体全文滚动 |
| PDF | 对话框内用浏览器查看 |
| Excel（xlsx）、Word（docx） | 提示暂不支持在线预览，请使用 **下载** 后用本地 Office 软件打开 |

## 8. Skill 广场

1. 打开 **Skill 广场**，浏览企业已发布的 Skill 卡片（名称、分类、简介）。
2. 点击 **查看详情** 阅读完整说明与 **推荐提问**。
3. 点击 **使用 Skill** 或 **去对话**，进入新对话并自动带上该 Skill。

若列表为空或加载失败，可使用页面上的 **重新加载**。

## 9. AI 同事

1. 打开 **AI 同事**，通过卡片查看名称和说明；打开详情后可查看已发布版本。
2. 在详情中查看 **开场提示** 与 **你可以这样问** 中的示例。
3. 点击 **开始对话** 进入专属会话。

每位 AI 同事的能力边界由其发布配置决定（绑定的 Skill、工具与企业数据范围等）。

## 10. 团队空间与个人空间

### 10.1 空间列表

在 **团队空间** 页面可以：

- 查看已加入的团队工作空间，以及名称、负责人、对话数、文件数、成果数和成员数等摘要信息
- 按空间名称、说明或负责人搜索
- 使用 **全部 / 活动 / 已归档** 筛选
- 点击 **创建团队工作空间**，填写名称和空间说明

个人对话和文件不在该列表中展示，请通过「新对话」、「历史对话」和「我的文件」使用。

### 10.2 空间内页签

进入某个空间后，顶部通常有三个页签：

| 页签 | 内容 |
| --- | --- |
| **对话** | 「新对话」与「历史对话」切换；空间内打开的对话不离开空间外壳 |
| **文件** / **共享文件** | 上传、查看版本、引用到对话；团队文件支持 **版本** 与 **上传新版本**（依角色与解析状态，引用按钮在可引用时显示） |
| **成果** | 卡片展示本空间生成的成果，可预览与下载 |

右侧 **空间信息** 面板提供成员、Agent 成员、动态通知、设置入口等（具体项依你的角色显示）。

### 10.3 成员角色（团队空间）

| 角色 | 典型能力 |
| --- | --- |
| **负责人** | 修改空间设置，管理员工成员和 AI 同事成员，查看用量，归档、恢复或转交空间等 |
| **管理员** | 协助管理员工成员；可在「成员」和「只读成员」之间调整角色，并查看用量；不能管理负责人、其他管理员或 AI 同事成员 |
| **成员** | 参与讨论、@ AI 同事执行、上传与引用文件（依策略） |
| **只读成员** | 查看讨论、文件与成果，不能发言、上传或发起执行 |

负责人可通过 **空间设置** 修改名称与说明、**转交负责人**、**归档空间** 或 **退出空间**。唯一负责人退出前必须先转交负责人。归档后，现任成员仍可在原有权限内查看和下载历史内容；负责人可恢复空间。

### 10.4 用量查看

团队空间的 **负责人** 与 **管理员** 可在空间信息中查看近期用量摘要（如 7 天窗口）；普通成员界面不展示用量入口。

## 11. 我的文件

路径：**我的文件**（`/files`）。

- **上传材料**：支持与新对话相同的办公文件类型。
- **搜索与筛选**：按文件名搜索；按来源筛选「个人材料 / 会话附件 / 生成成果」。
- **操作**：**引用到新对话**、**下载**、在允许时 **移除**；可跳转 **来源对话**（对话仍存在时）。
- 文件若未完成安全检查或解析，页面会显示相应状态。是否可引用、下载或移除，以当前文件行中实际显示的操作按钮为准。

团队资料请在对应 **团队空间 → 共享文件** 中查看。

## 12. 历史对话

路径：**历史对话**（`/history`）。

- 按标题关键词搜索。
- 按 **全部 / 我的对话 / 团队对话** 筛选。
- 点击条目进入会话继续查看或对话；团队条目显示空间名称，归档空间会标注 **只读**。
- 在允许时可 **移除** 对话记录。

侧栏 **最近对话** 提供快捷入口，与历史列表互补。

## 13. 自动任务

路径：**自动任务**（`/automations`）。

### 13.1 我创建的自动任务

点击 **新建自动任务**，填写：

| 字段 | 说明 |
| --- | --- |
| 任务名称 | 便于识别的标题 |
| 执行 Agent | 固定为创建时选中的 **已发布版本** |
| 结果归属工作空间 | 执行产生的会话与成果归属的个人或团队空间 |
| 执行规则 | **仅手动**、**每天** 或 **每周**（每周需选择星期） |
| 时间与时区 | 每日或每周任务需指定时刻；所有规则均需指定 IANA 时区（如 `Asia/Shanghai`） |
| 任务内容 | 每次执行使用的固定提示词（最长 4000 字） |

创建后，任务先保存为草稿。草稿或已暂停任务可编辑、试运行和启用；已启用任务可暂停或立即运行。所有未停用任务都可查看 **执行记录**，也可在不再需要时 **停用**。

启用时页面会明确提示：服务停机期间错过的定时任务不会补跑，执行失败也不会自动重试。如需再次执行，请查看记录后手动处理。

**执行记录** 抽屉中可查看触发方式、计划时间、受理与执行状态、**业务结果** 说明，并 **查看会话** 进入关联对话；进行中的运行可按页面提供的入口取消。

### 13.2 AI 同事主动任务结果

页面下方 **AI 同事主动任务结果** 展示由管理员配置的规则产生、且你是**结果接收人**的记录。你是结果的阅读者，不是该任务的执行身份。可刷新列表查看摘要与回答内容。

## 14. 常用操作速查

```text
想快速问一件事        → 新对话 → 输入问题 → 发送
想用标准能力包        → Skill 广场 → 使用 Skill
想指定某位 AI 同事    → AI 同事 → 去对话；团队对话中可输入 @ 选择
要分析一份表格        → 新对话 → + → 上传本地文件 → 描述分析需求
要和团队对齐后再让 AI 做 → 团队空间 → 对话 → 先发讨论 → @ 同事再执行
要每周固定出报告        → 自动任务 → 新建 → 选 Agent、空间、周期与提示词 → 启用
要找上周的对话          → 历史对话 → 搜索标题
要找下载过的成果        → 我的文件 → 筛选「生成成果」
```

## 15. 遇到问题时

- **看不到 Skill、AI 同事或团队空间**：先确认登录账号是否正确，再联系管理员确认内容是否已发布、你是否已获得成员资格。
- **文件无法引用**：查看文件的安全检查和解析状态；只有页面显示引用入口的文件才可加入对话。
- **任务失败或中断**：先阅读页面给出的原因和建议；当页面显示「重新执行本轮」时可手动重试，也可在输入框中补充信息后发起新一轮。
- **团队空间只读**：可能是空间已归档，或你的角色为「只读成员」。请联系空间负责人确认。
- **页面与本手册不一致**：部署环境可能尚未升级到本手册对应的版本，请以页面实际文案和管理员通知为准。
