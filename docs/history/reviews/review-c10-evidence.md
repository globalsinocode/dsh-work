# C10：Bootstrap 只用于显式首次认领

红灯：原代码普通 admin 登录要求 Bootstrap Scope；普通登录在无本地管理角色时进入自动认领。两个测试均失败。

修复：正常登录/刷新只使用基础 Scope；首次认领使用独立 /auth/admin/bootstrap 路径、全新安装显式开关及单次登录事务 intent。默认关闭可避免历史无账本环境被误判为新安装。消费账本一旦存在，即使管理员全被撤权也不重新开放；原子的 consumeAdminBootstrap 保留。

绿灯：Scope/首次认领/并发完成/无权限/错误上游响应单元与原身份单测均通过；PostgreSQL 测试验证 intent 单次消费、受众约束、认领幂等及撤销全部管理角色后仍保持关闭，联合原身份/目录同步集成通过。具体计数及日志在交付包。没有调用真实 AI Hub/OIDC。

迁移：仅新增 0042_oidc_login_bootstrap_intent.sql，不覆盖旧事务或伪造历史认领。不完整历史账本需受控对账；不得重新开启认领作为恢复后门。对用户本地新主线需检查迁移编号及名称冲突，已有迁移绝不覆盖。没有修改 TW-10/AG-03 或批次3页面。
