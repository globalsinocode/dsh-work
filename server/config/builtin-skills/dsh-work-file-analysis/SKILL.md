# 文件分析

适用于用户要求总结、解读、提取、比较、核对或统计其提供的文件内容。只是顺带提到文件、不需要读内容的问题不必使用。

## 步骤

1. **先摸清输入。** 用 `glob` 列出 `input/` 下的文件，确认每个文件的名称、类型和大致规模；解析文本在 `input/*.txt`，执行说明提到原始文件挂载时，原件在 `input/original/`。用户提到的文件不在其中时，直接说明，不要猜测内容。
2. **先看结构再读细节。** 长文件先读开头、目录、标题或表头，再用 `grep` 定位与问题相关的段落、工作表或页码，按需读取，不要只凭开头几段下结论。表格先确认列名、单位、行数和是否有合计行。
3. **数据用程序计算。** 求和、平均、占比、排名、同比环比等数值结论，在可以运行命令时用 `python3`（pandas、openpyxl）读取原始文件计算，不要心算或目测；计算前说明口径（筛选条件、单位、是否含合计行）。不能运行命令时只做文本层面的分析，并明确说明数值未经程序核对。
4. **区分事实与判断。** 原文写明的内容是事实；根据原文推出的是判断，要写明依据；原文没有的信息不要补充为事实。多份文件说法不一致时，并列给出并指出差异，不要擅自取舍。
5. **按问题组织结果。** 先给结论，再给支撑要点。多个对象或多份文件的对比用表格呈现；需要可下载的明细时，把整理后的表写成 `output/` 下的 CSV 或 Excel（Excel 方法见 Office 文档内置 Skill）。

## 输出要求

- 每条关键结论标注出处：文件名，加上页码、工作表名、章节或行号等可回查的位置。
- 引用原文只摘必要的短句，不大段复制。
- 涉及金额、日期、数量时保留原文单位和精度。

## 完成前自检

- 随机抽一两条结论回到原文核对，确认出处与内容一致。
- 检查是否有文件未读、被截断或读取失败（例如超出每轮输入额度、没有解析文本）；有则在回答中明确列出，并说明对结论的影响。
- 用户的问题是否每一部分都已回答；无法从文件中确认的部分要直说。
